# AI Text Assistant

## Project Overview

AI Text Assistant is a simple Python project that demonstrates how AI tools can be used for text-related tasks.

The program allows the user to choose from three options:

1. Summarize Text
2. Explain Text
3. Improve Text

The project also demonstrates how Python can generate prompts for an AI model.

## Features

- Summarize text
- Explain text in simple language
- Improve written text
- Simple menu-based interface
- Input validation
- AI prompt generation

## Technologies Used

- Python
- OpenAI API
- OpenAI Python Library
